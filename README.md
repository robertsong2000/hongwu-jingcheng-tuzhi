# 洪武京城图志

《洪武京城图志》是明初洪武年间纂修的南京城市志，记载明初都城（今南京）的宫阙、城门、山川、寺观、祠庙、官署、学校、桥梁、街市、楼馆、仓库、厩牧、园囿等规制，是研究明初南京城市布局的重要文献。

## 内容说明

本仓库收录据1929年扫叶山房石印本《洪武京城图志》逐页识读整理的文字稿：

- **洪武京城图志-简体字版.md** — 简体字横排版，含五幅古图（推荐阅读）
- **洪武京城图志-文字整理.md** — 繁体字横排版

## 原书信息

- **书名**：洪武京城图志
- **纂修**：明洪武二十八年（1395），礼部奉敕纂修
- **版本**：本整理稿据1929年扫叶山房石印本
- **原书体例**：竖排右起木刻，共六卷，含图十三幅

## 整理说明

- 原书为扫描影印件，无内嵌文字层，全部文字通过逐页视觉识读转录
- 原书竖排右起，整理稿改为横排左起，段落与条目仍依原书次第
- 木刻字迹多有漫漶，部分条目文字可能存在识读误差，学术引用建议对照原书核对
